# المرحلة 1: اختبار الجدوى على الآيفون

تطبيق اختبار صغير (Music Test). يستخرج صوت يوتيوب على هاتفك ويشغّله مباشرة دون تحميل، ويختبر:
- التشغيل والشاشة مقفلة
- الانتقال للأغنية التالية تلقائيًا
- أزرار شاشة القفل
- تبديل الشبكة وسط أغنية
- الجودتين: عادية واقتصادية

## 1) رفع المشروع إلى GitHub
1. افتح github.com/new:
   - الاسم: `music-ios`
   - اختر **Public**
   - لا تضف README
   - اضغط Create repository
2. فك الضغط عن `music-ios.zip` في `C:\music-ios`، بحيث يكون الملف `package.json` داخل `C:\music-ios` مباشرة.
3. في PowerShell:
```
cd C:\music-ios
git init
git add .
git commit -m "Phase 1 feasibility test"
git branch -M main
git remote add origin https://github.com/hakimraissi16/music-ios.git
git push -u origin main
```
إن طُلب تسجيل الدخول إلى GitHub فوافق في النافذة التي تظهر.

## 2) البناء (تلقائي)
1. الرفع يبدأ البناء وحده. افتح المستودع ثم تبويب **Actions**.
2. انتظر علامة ✓ خضراء (10–15 دقيقة).
3. افتح التشغيل، وفي الأسفل قسم **Artifacts** نزّل `MusicTest-ipa`.
4. فك ضغطه لتحصل على `MusicTest.ipa`.

إذا ظهرت ✗ حمراء: افتح الخطوة الفاشلة، وصوّر آخر الأسطر، وأرسلها لي.

## 3) التثبيت بـ Sideloadly
1. صِل الآيفون بالكابل وافتح Sideloadly.
2. **Apple account:** اكتب **الحساب الثاني** وليس حسابك الأساسي.
3. اسحب `MusicTest.ipa` إلى النافذة، ثم اضغط **Start**.
4. أدخل كلمة سر الحساب الثاني، ورمز التحقق إن طُلب.
5. على الآيفون: الإعدادات ▸ عام ▸ VPN وإدارة الجهاز ▸ اختر بريد الحساب الثاني ▸ **ثق**.
6. الإعدادات ▸ الخصوصية والأمان ▸ **وضع المطوّر** ▸ تشغيل. سيُعاد تشغيل الهاتف، وبعده أكّد التفعيل.
7. افتح تطبيق **Music Test**.

## 4) الاختبارات (بالترتيب)
ضع رابطَي أغنيتين **قصيرتين** (2–3 دقائق) لتصل للانتقال بسرعة.
المشغّل: **أصلي**، الجودة: **عادية**، الاستخراج: **visionOS**.

1. **الاستخراج فقط:** اضغط «اختبار الاستخراج فقط» على الواي فاي. هل ظهر ✔ أخضر؟
2. **التشغيل والقفل:** اضغط «استخرج وشغّل»، ثم اقفل الشاشة واترك الهاتف حتى تنتهي الأغنيتان.
   - هل استمر الصوت؟
   - هل انتقل للثانية وحده؟
3. **شاشة القفل:** هل يظهر الاسم والصورة؟ جرّب إيقاف/تشغيل، والتالي، وتحريك شريط الوقت.
4. **تبديل الشبكة:** أثناء التشغيل أطفئ الواي فاي من الإعدادات، لا من مركز التحكم. هل أكمل بعد ثوانٍ؟
5. **الجودة الاقتصادية:** غيّر الجودة وأعد الاختبار 2 باختصار.
6. **بيانات الجوال:** كرر الاختبار 1 والواي فاي مطفأ.
7. **مقارنة:** غيّر المشغّل إلى **ويب** وكرر الاختبار 2.
8. **عند أي فشل في الاستخراج:** جرّب طريقة «iOS (HLS)» ثم «Android VR».

## 5) أرسل لي النتائج
- اضغط **نسخ** في قسم السجل والصقه لي.
- اكتب نعم/لا لكل اختبار من 1 إلى 7.

السجل يُحفظ حتى بعد إغلاق التطبيق، فلا تقلق إن أغلقته.
